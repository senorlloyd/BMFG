CutContour Checker
Roland BN-40·VersaWorks·Print & Cut

Check your CutContour before you print.

Drop an Illustrator EPS to check its cut line before it goes to the BN-40. Any problems come with fix steps and a tutorial video. Your file stays on this computer and is never uploaded.

What a file needs to cut on the BN-40

Color mode
CMYK (File › Document Color Mode)
Cut line
A stroke with fill set to None
Swatch name
CutContour (case and spacing must match)
Swatch type
Spot Color
Swatch values
C0 M100 Y0 K0, 100% tint
Save as
Illustrator EPS (*.EPS)

The checker reads the Illustrator editing data saved inside the EPS, so it can tell a stroke from a fill and a spot swatch from a process swatch. Only EPS files saved from Adobe Illustrator are supported. Reference: Roland VersaWorks manual: When Using Adobe Illustrator.
